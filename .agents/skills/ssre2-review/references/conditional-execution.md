then inspect the full result for calibration. Reference shared receipts rather than recopying them into prompts.
Route observation requests and reasoning corrections as the contract specifies.

## Probe environment

Check existing receipts or an installed compatible environment first. External setup for a decisive probe is
within this skill's remit. When neither supplies the needed observation, create a time-boxed temporary
environment outside the target project and its dependency environment. Active network, execution, approval
and resource limits govern this setup. If a limit blocks it, return a claim-specific evidence gap and closing
path; continue independent work.
Record interpreter, manifest, setup/probe commands, exit status, decisive output and environment differences,
including failed setup. Stop at the resource limit or discriminating observation; return the receipt and cheapest
reproduction path to the contract's evidence-limit/succession handling.
