# SSRE2 Federation

Each lane keeps its own workflow, assurance, and judgments. A standalone SSRE2 run has no sibling dependency.

## Judgment ownership

| Lane | Judgment |
|---|---|
| Matt Pocock Codebase Design | General engineering structure: Module Depth, Interfaces, Seams, Leverage, and Locality. The skill supplies design principles and vocabulary. |
| Matt Pocock Code Review | Standards and Specification fidelity on a change relative to a fixed point. |
| SSRE2 Design and Review | Scientific meaning, regimes, correspondences, and evidence able to challenge the claims. |

For a Design-to-Spec handoff, use only the exact clauses that the responsible owner adopts and makes part of
the governing Spec for the change. Record the approval, Spec location, and Design identities. Other Design
proposals remain advisory. An adopted clause can carry intent from Design to implementation at a later revision.
SSRE2 Review establishes scientific support on its own target and evidence. Apply the source-alignment rule
below when sharing observations about implementation.

## Align the references

A **Sibling Reference** carries the sibling result or source location, source identity, inspection coverage, and
located facts. For a change review, record the effective comparison base, target, and whether working-tree
changes were included. For Matt Pocock Code Review's three-dot diff, the effective base is the merge base and
the target is the committed HEAD. Compare both with the actual SSRE2 review inputs.

Verify source identity and overlapping coverage before sharing located facts. Disclose mismatches and continue
independent work. Route any material observation discovered after sealing through the Scope owner and the Review
method's succession rule.

## Relate frozen results

After the relevant results freeze, link findings at verified shared source locations (same-locus). Preserve each finding's owner,
basis, and provenance. Explain the shared fact and each lane's consequence. Keep verdicts separate and use
located scientific evidence for scientific judgments. A late reference that only links already registered
facts can be cited in synthesis without changing a sealed Scope.
