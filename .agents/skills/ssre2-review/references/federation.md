# SSRE2 Federation

Read this file only when another design/review artifact or co-invoked skill is an input.

Codebase design owns Module depth, Interfaces, Seams, Leverage and Locality. Code review owns Standards and Spec.
SSRE2 owns scientific meaning, supported domains, correspondence and challenging evidence. Each lane retains its
workflow, assurance and judgments; no sibling is a runtime dependency.

A **Sibling Reference** carries source identity, inspection coverage and located facts. For change reviews,
record base/target identities and whether working-tree changes were included. Align source identities and state
coverage differences before sharing facts. Unmatched references remain outside same-source synthesis while
independent SSRE2 work continues.

Sibling judgments supply no scientific proof and SSRE2 does not rerank them. After SSRE2 results freeze, relate
only verified same-locus findings. Preserve each lane's conclusion, provenance and scientific relevance.
