SSRE2-DESIGN.md. Target code remains READ_ONLY.

Federate with codebase design by reference. It owns Module depth, Interfaces, Seams, Leverage, and Locality;
SSRE2 owns scientific meaning, regimes, lifecycle, correspondence, and evidence. Neither judgment substitutes
for the other.

## Run

   freeze the Design Frame and material `UNK` items.
2. Build the prospective Scientific Map and close its Identity Ledger traces. Inspect local variables only when

3. Produce one Design Projection per Scientific Dimension under Shared Doctrine's Execution economy.
4. Synthesize the fewest justified deep Modules behind small Interfaces and keep report detail proportional.
   Write the artifact only when every completion check is traceable.

modified. Hand off the artifact and closing paths; implementation follows.
