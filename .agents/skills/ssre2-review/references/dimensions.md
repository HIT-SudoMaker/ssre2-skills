# SSRE2 Review Dimensions

Apply only the assigned operator to the shared sealed Scope. Cite registered IDs and receipts; return missing
observation requests to the Scope owner. The Review contract owns result shape and calibration. The controller
alone owns cross-Dimension relations.

## Sonnet

Test faithful correspondence and visible asymmetry:

- State each material quantity, method or state relation with its expected behavior, normalization and regime.
- Trace public meanings and handoffs: owner, conditions, preserved meaning and changed meaning.
- Locate false equivalence hiding regime, precision, representation, determinism, failure or returned-state
  differences, and unexplained divergence where a relation should hold.

A finding names the correspondence, structural locus and observable prediction failure. Similarity proves nothing.

## Simple

Test coherent ownership behind deep interfaces:

- Locate owners of scientific objects, conversions, method/regime choice, state, invariants and evidence.
- Trace selection → computation → returned state. A deep interface hides incidental implementation knowledge;
  deleting it redistributes real complexity to callers.
- Locate duplicated formulas, thresholds, conversions, selectors or state rules with scientific consequence.

A finding cites the complete duplicate-owner or shallow-interface chain. File count and name length prove nothing.

## Reliable

Test observable enforcement inside the claimed domain:

- Recover unit/alias/normalization/tolerance contracts, supported regimes and selection ownership.
- Trace legal and invalid transitions, interruption, retry and re-entry. Locate invariant establishment, checking
  and exposure; after interruption inspect persistent truth and returned state.
- Seek plausible wrong success: scale or coordinate mismatch, out-of-regime method, invalid-state reuse, NaN/Inf
  or stale output. Request the cheapest unresolved edge/transition probe; fault-inject only a real scientific seam.

`FAIL` requires a triggerable supported-domain path. Presented support, rather than outside-domain reality,
defines the boundary.

## Evidenced

For every material `CLM` and `COR`:

- Identify the strongest analytic result, authoritative data, independent implementation or measurement.
- Challenge the claim under a declared normalization and regime through dimensions, agreement, limits,
  convergence, conservation, transforms, round trips or complementary outputs.
- Trace circularity through shared formulas, data, expectations, tolerances and conversions.
- Give each remaining gap the cheapest contradictory acquisition/probe and its independence limit.

A counterexample may satisfy the evidence obligation it challenges. `FAIL` requires an evidence-specific
contradiction, such as claimed independence defeated by a shared defect-bearing path. Otherwise an unfilled
material obligation is `UNPROVEN`. Carry the unproven ledger under every verdict.

## Evolvable

Test bounded propagation along observed scientific axes:

- Identify present variation in unit/scale, method, regime, representation, backend, precision, state or evidence.
- Trace one material change through Interfaces, owners, selectors, transitions, returned states, tests and evidence;
  report the actual modification set and where propagation stops.
- Locate shadow selectors, duplicate state machines and wrappers or registries without real responsibility. Apply
  the Adapter Seam rule; a single implementation or pure calculation creates no seam obligation.

Bounded, explainable change is the criterion. Zero touched files and hypothetical flexibility prove nothing.
