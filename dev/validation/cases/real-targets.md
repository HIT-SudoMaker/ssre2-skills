# Real scientific repository targets

Release-grade SSRE2 behavioral claims use public scientific repositories. Local fixtures may exercise executor
branches, but they do not establish scientific defect recall, clean-control precision, Design quality, reflexive
stability, or Federation benefit.

All revisions below identify repository history, not installed package versions. A target is eligible for blind
model replay after its identity, Module-sized file range, brief, and hidden grading criteria are frozen. Local
execution is optional evidence acquisition and never a prerequisite for Design, Review, or Federation replay.

Evidence independence is an experimental condition applied to scientific efficacy cases: compare repository tests,
issue examples, and an independently specified reference. Federation integrity runs standalone lanes, later
Sibling Reference intake, and simultaneous co-invocation on the same exact target identity. Freeze each lane
before synthesis, preserve Standards, Specification, and five scientific verdicts separately, and include a
deliberately mismatched reference control. Neither condition requires an invented scientific codebase.

## Eligibility classes

- **Negative boundary:** a real scientific repository change with no in-scope testable scientific behavior. Freeze
  target, file range, and a preregistered no-finding boundary. It needs no scientific reproduction or reference.
- **Scientific efficacy:** a real issue or specification and frozen target history with a hidden, independently
  adjudicated CLM/COR and regime reference. Historical repair evidence may grade the model after outputs
  freeze; local execution is requested only when a decisive observation is still needed.
- **Protocol control:** a missing Artifact Route, target mismatch, late evidence, unavailable ISOLATED context, or
  interruption injected around a real Scope. It scores recovery and authority limits, never scientific quality.

## Control semantics

A post-fix target is a **claim-bounded clean control**. It is clean only for preregistered CLM/COR and regimes.
Later issues or unrelated defects do not invalidate that control, and the control never
licenses support for a whole Module or repository.

For Design runs, expose the issue brief and pre-fix target while hiding the merged repair. Compare the frozen
Design report with the repair only after delivery. For Review runs, expose the selected difference or target but
keep the grading reference and successor history hidden until all five results freeze.

Every blind replay supplies:

- a real repository identity, exact exposed target revision or difference, Module-sized file range, and verbatim
  brief;
- hidden grading criteria frozen before the model run;
- skill, model, executor, and host identities, Run Summary, artifact paths, material Open Items, assurance, Use
  Record, and target non-mutation records;
- an explicit eligibility class and scientific-denominator membership.

Every scientific efficacy case additionally supplies a public issue or specification, pre-fix and fixed history,
claim-bounded clean control, independent CLM/COR and regime reference, and an adjacent hard negative
when available. Commands, environments, and decisive outputs are recorded only for a requested targeted check;
`not requested` is a valid check result.

## macOS execution profile

Static blind replay is platform-independent and starts with frozen source packages. When a decisive targeted check
is requested, prefer the lowest-cost compatible target: mpmath, Pint, and Zarr should be simpler on Apple silicon.
For SciPy, record Python, NumPy, linear-algebra libraries, compiler or binary distribution, and machine
architecture. An emulated x86-64 observation has a separate environment identity.

The executor exposes an immutable target and writes only to a run directory or allowed temporary directory. A
targeted-check environment stays outside the target and receives a separate identity. Controller injections score
protocol recovery and mutation limits only; they do not increase the scientific denominator.
