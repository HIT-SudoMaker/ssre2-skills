# SSRE2 Reflexive Closure

Read this file only when frozen SSRE2 bytes are the target.

1. Freeze target bytes before the run and record executor identity separately.
2. Keep current output outside the target; it may enter only a successor run.
3. Treat self-produced support as same-path evidence, never independent proof of the Kernel.
4. With unchanged target, authority, and evidence, prose may vary but material identities may not. New material
   content means earlier intake was incomplete.
5. A material Kernel, claim, regime, evidence, or target change creates a successor run that preserves its
   predecessor.

Reflexive closure is complete when target, executor, and output identities are separate; self-evidence limits are
explicit; and every material change has a successor or recovery path.
